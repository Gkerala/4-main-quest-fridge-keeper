# 사진 모으기 (검증용)

1. 관리할 품목을 `items.json`에 모두 적는다(지금: 우유, 시금치, 닭가슴살). 품목을 더하면 `en`(영어 이름), `ko`(한국어 설명)도 함께 적는다.
2. 품목마다 **2~4장**, 모두 합쳐 **15~20장**을 찍어 `data/photos/`에 넣는다.
   - 섞을 것: 날짜가 잘 보이는 사진 / 날짜가 작거나 빛이 반사된 사진 / 날짜가 없는 사진(시금치 등) / 냉장고 안에서 다른 물건과 같이 찍힌 사진
   - 사진 한 장에는 **관리할 품목 하나**만 주인공으로.
   - 사람 얼굴, 집 주소가 적힌 택배 송장 등은 찍히지 않게. (저장소는 공개된다)
3. **모델을 돌리기 전에** 정답을 `data/labels.csv`에 적는다.
   ```
   file,name,expiry
   milk_01.jpg,우유,2026-11-30
   spinach_01.jpg,시금치,
   ```
   날짜가 안 찍힌 사진은 expiry를 비운다.
4. 실행: `.venv\Scripts\python evaluate.py` → `results/`에 표가 생긴다.
