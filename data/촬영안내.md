# 사진 모으기

관리 품목 6개: 우유(플라스틱 통), 두유(팩), 시금치(날짜 없음), 닭가슴살 팩, 고구마(날짜 없음), 홍삼(소비기한 있음).

## 1. 기준 사진 (벡터 검색 `ref` 방법용)
- 품목마다 **2~3장**을 `data/refs/<품목 이름>/`에 넣는다. 예: `data/refs/우유/1.jpg`
- 검증 사진과 **다른 사진**이어야 한다(같은 사진이면 시험 답을 보고 푸는 셈).

## 2. 검증 사진
- 품목마다 **3~4장**, 합쳐서 **20장 안팎**을 `data/photos/`에 넣는다.
- 섞을 것: 날짜가 잘 보이는 사진 / 날짜가 작거나 빛이 반사된 사진 / 날짜가 없는 품목 / 냉장고 안에서 다른 물건과 같이 찍힌 사진
- 사진 한 장에는 **관리할 품목 하나**만 주인공으로.
- 사람 얼굴, 주소가 적힌 송장 등은 찍히지 않게. (저장소는 공개된다)

## 3. 정답 먼저 적기 (모델 돌리기 전)
`data/labels.csv`
```
file,name,expiry
milk_01.jpg,우유,2026-11-30
spinach_01.jpg,시금치,
```
날짜가 안 찍힌 사진은 expiry를 비운다. 파일 이름은 영문이 안전하다.

## 4. 실행
`.venv\Scripts\python evaluate.py` → `results/summary.json`(방법별 정답률, 가장 좋은 방법), `recognition.csv`, `expiry.csv`
